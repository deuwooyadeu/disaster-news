# 재난·사고 뉴스 수집 키워드
# '#'으로 시작하는 줄과 빈 줄은 무시됩니다.
# 키워드를 추가/삭제해도 스크립트 수정은 필요 없습니다.
#
# ── 설계 원칙 ──────────────────────────────────────────────
# 네이버 검색 API는 한 키워드당 하루 1,000건까지만 조회할 수 있습니다.
# 그래서 넓은 말(화재, 폭염, 호우, 소방당국)을 그대로 쓰면 한도에 걸려
# 그날 이른 시간대 기사가 통째로 잘립니다.
#
# 원칙 셋:
#   1. 넓은 상위어 대신 피해 형태로 쪼갠다 (호우 → 주택침수/도로침수/하천범람)
#   2. 같은 기사를 여러 번 훑는 중복 키워드를 없앤다 (호우+폭우+집중호우)
#   3. 정밀도가 낮으면서 한도만 잡아먹는 그물 키워드는 뺀다 (소방당국, 인명피해)
